# Contributing

El Rudo is maintained as an open source Unity and Web3 game prototype. Small,
focused contributions are preferred.

## Useful Areas

- Documentation fixes for setup, gameplay, contracts, and backend services.
- Solidity contract review, tests, and deployment notes.
- Unity project cleanup, bug fixes, and reproducible build steps.
- Backend improvements for Moralis cloud functions and AWS Lambda combat logic.

## Workflow

1. Open an issue describing the change or bug before large pull requests.
2. Keep pull requests focused on one topic.
3. Include screenshots or reproduction steps for gameplay/UI changes.
4. Update documentation when setup or behavior changes.
5. Do not commit generated build outputs, debugger binaries, local settings, or private keys.

## Local Checks

Before opening a pull request:

- Confirm the Unity project opens with Unity 2021.2.19f1 or document the version used.
- Review Solidity changes for compiler warnings.
- Run any affected local gameplay flow manually and describe what was tested.
