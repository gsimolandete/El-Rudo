# Security Policy

## Reporting Security Issues

Please do not open a public issue for vulnerabilities involving smart contracts,
wallet flows, private keys, authentication, or backend endpoints.

Report security concerns privately to the repository maintainer through GitHub.
Include:

- A short description of the issue.
- Steps to reproduce or affected files.
- Potential impact.
- Suggested fix, if known.

## Scope

Security-sensitive areas include:

- Solidity contracts in `Remix/contracts`.
- Wallet connection and transaction flows in the Unity project.
- Moralis cloud functions.
- AWS Lambda combat/backend logic.

## Notes

This repository is an open source game prototype. Code review and automated
checks are welcome, but no published version should be treated as a completed
security audit unless explicitly stated in a release.
